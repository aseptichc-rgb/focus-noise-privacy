Ritono 1.19 (20) — foreground services

Google Play review demonstration of the unchanged, signed Android release APK on Android 17. This screen recording contains no audio track, sign-in credentials or personal account details. The session records shown were created by local verification.

Media playback

The user chooses Rain, taps Start focus, turns the screen off and on, then pauses, resumes and finishes the session. The selected sound plays locally during the active session, including while the screen is off. Media playback uses FOREGROUND_SERVICE_MEDIA_PLAYBACK and provides playback notification and media-session controls. User pause stops sound; Finish and save ends the session and its foreground service.

Silent focus timer

The user opens Choose sound, turns Use background sound off, then taps Start focus. No sound is played. FOREGROUND_SERVICE_SPECIAL_USE keeps the user-started focus session, elapsed-time tracking and ongoing timer notification alive while the screen is off. The video shows No sound with the timer continuing after screen-off. User pause freezes the interval and Continue resumes the same session.

This is not unattended or scheduled work. The service starts only after the user starts or resumes a session. Unexpected system deferral or interruption would stop the requested timer, disrupt phase transitions or lose the active interval. Users can intentionally pause or finish from the app or notification. The timer does not measure attention, monitor other apps, or collect sensor/location data. Focus records are stored locally.

The signed release verification additionally confirmed Finish and save stores the actual interval; breaks, pauses and sound-only sessions are excluded from focus totals.
